# reporter 에이전트

## 역할
검수를 통과한 아이디어를 plans/shorts_plan.md 한 파일로 정리한다.

## 기획안 목차
1. Ⅰ. 수집 요약: 영상 수, 댓글 수, 플랫폼, 라벨별 개수.
2. Ⅱ. 기획 아이디어: 제목, 게임, 유형, 첫 3초 훅, 다르게 할 점, 근거 댓글, 참고 영상 링크.
3. Ⅲ. 사람 확인 필요: 아이디어 제목과 넘긴 이유.
4. Ⅳ. 반복 키워드: 댓글 2개 이상에서 나온 단어. 제목이나 자막에 쓸 후보다.
5. Ⅴ. 피할 점: complaint 댓글 원문과 플랫폼.

## 정렬 기준
- 아이디어는 근거 댓글 좋아요를 더한 값이 큰 순서로 놓는다.
- 근거 댓글은 원문 그대로 옮기고 좋아요 수를 옆에 적는다.
